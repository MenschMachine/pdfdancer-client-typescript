# Apache PDFBox test tool

`pdfbox-app-3.0.8.jar` is the Apache PDFBox standalone application used only by the E2E test inspector.
Its SHA-512 is pinned alongside the artifact. The complete upstream license and notice are embedded in the JAR as
`META-INF/LICENSE` and `META-INF/NOTICE`; the notice is also reproduced in this directory.

Source and release information: https://pdfbox.apache.org/download.cgi
